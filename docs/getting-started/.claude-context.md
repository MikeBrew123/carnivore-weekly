## Automation Workflow

### Weekly Update (Every Monday)
1. **Fetch Videos:** `fetch_videos.py` pulls latest carnivore YouTube content
2. **AI Analysis:** `content_analyzer.py` uses Claude to analyze trends
3. **Sentiment:** `add_sentiment.py` analyzes comment sentiment
4. **Generate Pages:** Creates homepage, archive, channels
5. **Newsletter:** AI-generated unique weekly newsletter
6. **Deploy:** Auto-commits → triggers GitHub Pages deployment

### Newsletter Distribution
- `scripts/generate_newsletter.py` renders HTML → `newsletters/latest.html`
- `scripts/publish_to_beehiiv.py` pushes to Beehiiv as a draft (run manually, then send from Beehiiv UI)
- Beehiiv handles subscriber management, recommendation network, and CAN-SPAM footer
- Cloudflare Worker `POST /api/v1/subscribe/newsletter` → Beehiiv subscriber API (homepage signups)
- n8n drip (days 1–7) still runs via MailerLite for starter-plan signups — separate from newsletter

## AI Agent Deployment Matrix

**⚠️ CRITICAL: Check AGENT_DEPLOYMENT_MATRIX.md for agent deployment rules before launching any agents**

Located: `AGENT_DEPLOYMENT_MATRIX.md` (project root)

### Quick Rules
- **1 Agent (70% of tasks):** Single-perspective content (blog posts, welcome messages, how-tos)
  - Deploy the single best agent for content type
- **2 Agents (25% of tasks):** Different angles on same topic
  - Deploy Sarah + Marcus (parallel) OR Sarah + Chloe OR Marcus + Chloe
- **3 Agents (5% of tasks):** Comprehensive coverage
  - Deploy Sarah + Marcus + Chloe (all in parallel)
- **4+ Agents: NEVER** - Confusion and redundancy

### Available Agents & Skills
1. **Sarah** (Evidence-Based Expert)
   - Default skills: copy-editor, carnivore-brand, ai-text-humanization, seo-validator
   - Use for: Research-focused, health mechanisms, scientific claims

2. **Marcus** (Protocol & Performance)
   - Default skills: copy-editor, carnivore-brand, ai-text-humanization, soft-conversion
   - Use for: Practical guides, optimization, efficiency content

3. **Chloe** (Community & Connection)
   - Default skills: copy-editor, carnivore-brand, ai-text-humanization, soft-conversion
   - Use for: Welcome messages, community content, human stories

### On Every Session
✅ **ALWAYS check:**
1. Read AGENT_DEPLOYMENT_MATRIX.md before deploying any agents
2. Match task type to agent profile
3. Assign correct skills per agent
4. Deploy in parallel when using 2-3 agents (not sequentially)
5. Document which agents were deployed and why
